# Интерьерный блог — дизайн-проект

Вёрстка страницы статьи о дизайне интерьера с адаптивом и каруселью.

## Технологии

- HTML5
- CSS3 (Flexbox, медиа-запросы)
- Vue 3 (через CDN)
- Google Fonts (Inter, Oswald)

## Особенности

- ✅ Адаптивная вёрстка (мобильные планшеты десктоп)
- ✅ Хедер с фоновой картинкой
- ✅ Двухколоночные блоки с изображениями
- ✅ Карусель статей с кнопками управления
- ✅ Vue 3 без сборки (чистый CDN)
